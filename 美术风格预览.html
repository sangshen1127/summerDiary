04 — Design Tokens

设计 Token

可直接复制进 frontend/src/styles/theme.css。 组件只引用语义层，不直接用主色 —— 这样改配色时组件代码一行不动。

/* ── 主色 ── */ --c-mist: #F7F4EC; /* 晨雾白 页面底 */ --c-sage: #A8BFA5; /* 鼠尾草绿 主品牌 */ --c-haze: #A9C3D6; /* 雾蓝 信息态 */ --c-wood: #D8C3A5; /* 浅木色 描边 */ --c-cream: #FFF9F0; /* 奶油白 卡片底 */ /* ── 辅助色 ── */ --c-moss: #6F8F6A; /* 苔藓绿 成功态 */ --c-honey: #E8C87A; /* 蜂蜜黄 高亮 */ --c-lilac: #B9A7C9; /* 干花紫 记忆模块 */ --c-maple: #C97B6A; /* 枫叶红 点缀 <2% */ /* ── 中性色（带绿灰倾向，不用纯灰）── */ --n-900: #3A4238; /* 标题 */ --n-700: #55604F; /* 正文 */ --n-500: #7C8778; /* 次级 */ --n-300: #B8C2B2; /* 占位符 */ --n-200: #D6DDD1; /* 边框 */ /* ── 圆角（16-24px）── */ --r-sm: 12px; --r-md: 16px; --r-lg: 20px; --r-xl: 24px; /* ── 阴影（绿调，非纯黑）── */ --sd-sm: 0 1px 3px rgba(85,96,79,.05), 0 3px 8px rgba(85,96,79,.05); --sd-md: 0 2px 6px rgba(85,96,79,.06), 0 8px 20px rgba(85,96,79,.07); /* ── 动效 ── */ --ease-soft: cubic-bezier(.4, 0, .2, 1); --dur-fast: 220ms; --dur-base: 360ms; --dur-slow: 600ms; --dur-breathe: 5.5s;
Token 分两层：主色层（--c-*）定义原始色值， 语义层（--bg-* / --text-*）定义用途。 组件只允许引用语义层。这样将来做深色模式或换配色， 只需重定义语义层的映射，组件代码完全不动。
05 — Icons

图标风格

细线 + 轻微填充。统一规则：24×24 viewBox、 stroke-width 1.3–1.5、圆头圆角连接、 关键部位填 10%–14% 透明度同色。

功能图标 · 界面操作用（12 个）
"轻微填充"的分寸：填充透明度控制在 0.10–0.14。 高于 0.2 会变成"实心图标"，失去线条的轻盈感； 完全不填则显得单薄。填充只用在主体块面（叶片、云朵、水滴内部）， 不填细节线条。

组件

按钮 · 纸签与贴纸
纸签感怎么做出来的：主按钮在 box-shadow 的第一层加了一道 0 1px 0 #8AA886 —— 这是"纸的厚度"。 普通按钮只有模糊投影，看起来是浮在空中； 加这一道实体边就变成了"贴在纸上的纸签"。 按下时这道边消失（:active 时把 1px 改成 0）， 模拟纸签被压平。

07 — Empty State & Mascot

空状态与看板娘

看板娘是低存在感的自然精灵，只出现在三个地方： 空状态、加载中、鼓励语。它不抢内容 —— 所以这一版方案选择线条小生物而非人物立绘。

看板娘的三条纪律： ① 只在空状态、加载中、鼓励语出现 —— 有日记内容时绝不出现； ② 小尺寸场合不超过 104px（页头主视觉是唯一例外，见 07b）； ③ 表情克制 —— 闭眼、微动，不做夸张表情或大动作。

为什么默认用线条小生物，而不是人物立绘：人物立绘（哪怕是 Q 版）天生吸引视线， 而"低存在感"要求它必须能被忽略。线条小生物既可以有生命感， 又不会和日记内容争注意力，也避开了"复刻知名角色或 IP"的风险。 你自己画的立绘放在页头（那里本来就需要一个主视觉，不存在"争注意力"的问题）—— 两种做法并不冲突，详见下一节。

08 — Loading

加载动画

四种加载态。共同原则：周期 2.4 秒以上， 配合缓动曲线而非线性 —— 快速闪烁的加载动画会制造焦虑，与"治愈"相反。

动效的可访问性：必须尊重系统的"减弱动态效果"设置。落地时加这段：

@media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation-duration: .01ms !important; animation-iteration-count: 1 !important; transition-duration: .01ms !important; } }

用户开了这个设置通常是因为动效会引起不适（前庭功能障碍）。忽略它是不合格的。
