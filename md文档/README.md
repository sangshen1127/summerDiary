## ⚠️ 三个必须先知道的结论

### 1. DeepSeek 没有 Embedding API

你选了 DeepSeek 做 Chat 模型，但 **DeepSeek 不提供 Embedding 接口**，而 Phase 5 的语义检索必须要它。

→ **Chat 与 Embedding 是两个独立配置项。** 在 Phase 5 开始前（约第 4 周）补一个 Embedding 提供商，推荐阿里云百炼 `text-embedding-v3`（1024 维，有免费额度）。

### 2. LangChain4j 的依赖冲突是"运行期才炸"

它带入的 OkHttp / Jackson / Reactor 与 Spring Boot 3 的 BOM 冲突时，**编译完全正常，启动或调用时才报 `NoSuchMethodError`**。

→ **Phase 0 模块 0-2 就做一次带 LangChain4j 依赖的空应用启动验证。** 详见开发文档 §6.1。

### 3. 同学的 AI 模块不会阻塞你

AI 侧全部通过 `AiClient` / `VectorStore` 接口隔离，我提供 `MockAiClient` 返回符合规范的固定 JSON。

→ **在同学一行代码都没写的情况下，你也能独立完成并验收 Phase 0 到 Phase 3。**
